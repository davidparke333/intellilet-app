# IntelliLet

The IntelliLet lettings app: Next.js on Vercel, with the database, logins and files in Supabase (London).

- Database setup files are kept separately (001–004 SQL files).
- Settings needed on Vercel: `NEXT_PUBLIC_SUPABASE_URL` and `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY` (see `.env.example`).
